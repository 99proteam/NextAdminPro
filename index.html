Frequently asked questions

Is NextAdminPro really free?+

Yes. NextAdminPro is 100% free and open source under the MIT license. You can use it for personal projects, client work and commercial SaaS products without paying anything.

Which version of Next.js does it use?+

NextAdminPro is built on Next.js 16 with the App Router, React 19, TypeScript, Tailwind CSS v4 and Radix UI primitives.

Can I connect it to my own database or API?+

Yes. All pages read from a typed data layer in src/lib/data. Replace the mock data with Prisma, Drizzle, Supabase, Firebase or any REST/GraphQL API.

Does it include authentication?+

It ships with polished login, register and forgot-password pages. Plug in Auth.js, Better Auth, Clerk or Supabase Auth to make them work.

Is it compatible with shadcn/ui?+

Yes. The components follow the same patterns as shadcn/ui (Radix UI + Tailwind CSS + class-variance-authority), so you can add shadcn components alongside them.
